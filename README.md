# Power System Fault Analysis Using MATLAB/Simulink

## Overview
This project focuses on modelling and analysing different types of faults in a power transmission system using MATLAB/Simulink.

## Objectives
- Simulate line-to-ground (L-G) faults.
- Simulate line-to-line (L-L) faults.
- Simulate double-line-to-ground (L-L-G) faults.
- Simulate three-phase faults.
- Analyse fault currents and voltage profiles under different fault conditions.
- Study the role of protective relays in power system protection.

## Tools Used
- MATLAB
- Simulink
- Power System Analysis
- Power System Protection
